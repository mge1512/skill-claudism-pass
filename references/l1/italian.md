# Italian first language

Read `common.md` first.

## False friends

| Written | Means in Italian | English intended |
| --- | --- | --- |
| actually | attualmente | currently |
| eventually | eventualmente | possibly |
| argument | argomento | topic, subject |
| attend | attendere | wait |
| realize | realizzare | carry out, build |
| sensible | sensibile | sensitive |
| comprehensive | comprensivo | understanding, sympathetic |
| pretend | pretendere | demand, expect |
| confront | confrontare | compare |
| firm | firma | signature |
| education | educazione | manners, upbringing |
| delusion | delusione | disappointment |
| casually | casualmente | by chance |
| individuate | individuare | identify |
| parents | parenti | relatives |
| library | libreria | bookshop |

"Firma digitale" is a digital signature, not a digital firm. In supply-chain
and signing topics this one matters more than usual.

## Structure

- "Depend from" -> "depend on". "Different than" -> "different from".
- "In the university" -> "at the university".
- "I have 30 years" -> "I am 30".
- "The people is" -> "the people are".
- Italian keeps the article before possessives and abstract nouns: "the life is
  hard" -> "life is hard".
- Long periodic sentences with several dependent clauses. English technical
  prose breaks them up.

## Register

Italian professional writing is more elaborate than English technical writing.
Courtesy formulas that read as respectful in Italian read as padding in
English. Open with the point.
