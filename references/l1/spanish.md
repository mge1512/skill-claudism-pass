# Spanish first language

Read `common.md` first. Most of it applies to Portuguese as well.

## False friends

| Written | Means in Spanish | English intended |
| --- | --- | --- |
| actually | actualmente | currently |
| eventually | eventualmente | occasionally, possibly |
| realize | realizar | carry out, perform |
| assist | asistir | attend |
| compromise | compromiso | commitment |
| pretend | pretender | intend, aim to |
| discuss | discutir | argue |
| introduce | introducir | insert, enter |
| sensible | sensible | sensitive |
| support | soportar | withstand, tolerate |
| carpet | carpeta | folder |
| library | librería | bookshop |
| success | suceso | event, incident |
| advertisement | advertencia | warning |
| large | largo | long |
| fabric | fábrica | factory |
| billion | billón | trillion |

"We have a compromise with the customer" says the opposite of "compromiso".
Write "we have a commitment to the customer".

## Structure

- Spanish drops the subject pronoun; English does not. "Is important that we
  test" -> "It is important that we test".
- "Depend of" -> "depend on". "In the other hand" -> "on the other hand".
- "Explain me the change" -> "explain the change to me".
- "The same that" -> "the same as".
- Double negation is required in Spanish and wrong in English.
- Sentences are longer and more subordinated than English tolerates. One idea
  per sentence.
- "Assist to the meeting" -> "attend the meeting".

## Register

Spanish business writing opens and closes more elaborately than English. The
English equivalent of a full formal opening is usually "Hello" plus the point.
