# French first language

Read `common.md` first.

## False friends

| Written | Means in French | English intended |
| --- | --- | --- |
| actually | actuellement | currently |
| eventually | éventuellement | possibly |
| delay | délai | lead time, deadline |
| sensible | sensible | sensitive |
| assist | assister | attend |
| demand | demander | ask |
| control | contrôler | check |
| propose | proposer | offer |
| achieve | achever | finish, complete |
| prevent | prévenir | warn, notify |
| support | supporter | tolerate, withstand |
| formation | formation | training |
| material | matériel | hardware |
| notice | notice | manual, instructions |
| important | important | large, substantial |
| deception | déception | disappointment |
| library | librairie | bookshop |

"The delay is two weeks" reads as a slip in English where "délai" meant the
lead time. Write "the lead time is two weeks" or "it takes two weeks".

## Structure

- "In a first time" (dans un premier temps) -> "First" or "To start with".
- "I am agree" (je suis d'accord) -> "I agree".
- "I propose you to review" -> "I suggest that you review" or "please review".
- "In the same time" -> "at the same time".
- "Even if" is used where English needs "even though". "Even if" introduces a
  hypothetical, "even though" a fact.
- Long sentences with several relative clauses. Split them.
- Nominal style, as in German: "the realisation of the deployment of" ->
  "deploying".

## Typography

French sets a thin space before `;` `:` `!` `?` and inside `« »`. English sets
none, and uses straight double quotes. Guillemets do not survive into English
text.

## Register

French business register is more formal than English technical register.
"Veuillez agréer" has no English equivalent; "Best regards" is the whole
closing. "Please find enclosed" can usually become "attached is" or "here is".
