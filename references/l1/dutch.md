# Dutch first language

Read `common.md` first.

## False friends

| Written | Means in Dutch | English intended |
| --- | --- | --- |
| eventually | eventueel | possibly |
| actual | actueel | current |
| globally | globaal | roughly, approximately |
| control | controleren | check |
| meaning | mening | opinion |
| monster | monster | sample |
| agenda | agenda | calendar, diary |
| planning | planning | schedule |
| beamer | beamer | projector |
| solicit | solliciteren | apply for a job |
| brutal | brutaal | cheeky |
| sympathetic | sympathiek | likeable |
| miljard | miljard | billion (10^9) |

"Globally we need two weeks" says something quite different from "globaal".
Use "roughly".

## Structure

- Verb-second inversion carries over: "Yesterday deployed we the update" ->
  "Yesterday we deployed the update".
- "moet niet" is not "must not". See `common.md`.
- "I have that not seen" -> "I have not seen that".
- Overuse of "shall". English technical prose uses "will" for the future and
  reserves "shall" for normative requirements in specifications.
- "the both" -> "both".

## Register

Dutch business communication is direct, and the same directness in English
reads sharper to readers from most other cultures, because English hedges more.
This is not an error to correct; it is a difference to be aware of when the
audience is international. "This is wrong" carries further in English than the
writer usually intends. "This does not match the specification" says the same
thing without the edge.
