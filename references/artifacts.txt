# Leaked scaffolding and chatbot boilerplate. grep -E, case-sensitive unless the
# pattern says otherwise. One extended regular expression per line.
#
# These are not style. They are tool-call, citation and prompt scaffolding that
# chat products leak into copied text, plus conversation boilerplate that nobody
# writes into a document on purpose. A style tell suggests; these convict, and
# the token itself is noise, so a hit is always a removal.
#
# Contributed by Andy Fitzsimon (SUSE) from the Lolly project, CC0 1.0. The
# 2026 additions come from leaked system prompts
# (https://github.com/asgeirtj/system_prompts_leaks,
# https://github.com/elder-plinius/CL4R1T4S) and Wikipedia's "Signs of AI
# writing". Most of them show what a model is told to emit; few have been
# reported in pasted text yet. tests/docs/scaffolding.md has one sample of
# each.
#
# Two patterns deliberately keep their bracket context: bare "contentReference"
# and bare "attached_file" are ordinary identifiers in hand-written code.
#
# Tags are written with the first letter in brackets ("<[i]nvoke"). The class
# matches the same text and keeps the literal tag out of this file, which some
# content filters would otherwise quarantine. Tokens outside ASCII (the U+3010
# reference brackets of 2026 ChatGPT output, dagger citations) are matched in
# scripts/scan.sh, so this file stays ASCII.
